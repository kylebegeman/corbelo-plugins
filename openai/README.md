# Corbelo

An opinionated foundation and human-designed product features for your AI to
build on. Software for your business, your next idea, or yourself.

## Start here

1. Install the package for your platform, or add the public HTTP MCP connection
   at `https://corbelo.dev/corbelo/mcp` with authentication set to **None**.
2. Start a new chat and ask: "Use Corbelo to help me plan a small app for tracking
   equipment I lend to friends. Start with the simplest useful version."
3. Use **corbelo-discover** to find a starting point, **corbelo-build** to plan and
   integrate in a supported workspace, or **corbelo-extend** to grow an existing app.

The connection reads public catalog information. It needs no Corbelo account,
never installs code, and cannot access your project. Building needs a coding
workspace with the Corbelo CLI or local MCP tools, configured separately from
this hosted connection. A general chat can prepare a plan and hand you over to
that workspace. Downloads and supported environments: https://corbelo.dev/download/.

The free foundation lets you evaluate source. Paid feature source uses your own
Pro access in the existing local workflow. Never paste a key into chat. During
coming-soon mode, payments remain disabled; reservations are not paid access.

Help and installation: https://corbelo.dev/build-with-ai/
Local connection and private keys: https://corbelo.dev/docs/keys/
Privacy: https://corbelo.dev/privacy/
Support: hello@corbelo.dev
